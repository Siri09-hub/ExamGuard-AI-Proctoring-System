# Project Documentation

## Project Title
Development of Smart Examination Monitoring Platform with Integrity Analysis & Reporting System

## Project Name
ExamGuard AI Proctoring System

## 1. Introduction
ExamGuard is an AI-assisted online examination monitoring platform designed to improve examination integrity. The system monitors candidate activity, verifies identity, detects suspicious events, calculates integrity scores, classifies risk levels, and provides analytics and reports.

## 2. Objectives
- Verify candidate identity.
- Monitor examination activities.
- Detect and record suspicious events.
- Generate candidate warnings.
- Calculate examination integrity scores.
- Classify candidate risk levels.
- Provide administrator analytics.
- Generate examination integrity reports.
- Support testing and validation of the complete workflow.

## 5. System Workflow
1. Candidate registers with valid details.
2. Candidate logs into the system.
3. Candidate identity is verified.
4. Examination starts.
5. Candidate activity is monitored.
6. Suspicious events are detected and logged.
7. Warnings are generated when required.
8. Integrity score is calculated.
9. Candidate risk level is classified.
10. Administrator reviews examination analytics.
11. Examination data and reports can be reviewed and exported.
